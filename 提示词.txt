# 追星周边拼车平台 MVP 网页开发

请作为一名全栈开发工程师和 UI/UX 设计师，帮我直接开发一个完整、可运行、可交互的追星周边拼车平台网页。

不要只生成静态原型，需要实现完整的前端业务流程。

## 一、产品定位

这是一个帮助粉丝发起、寻找和加入偶像周边拼车的平台。

主要有两类用户：
- 车主：发起拼车、管理车次、确认拼成。
- 车员：浏览拼车、选择商品位置、加入拼车、进入拼车群。

同一个用户可以同时作为车主和车员。

## 二、技术要求

使用 React + TypeScript + Tailwind CSS。

使用 localStorage 保存数据，无须配置后端。

使用模拟账号切换身份，使用模拟支付，不接入真实支付接口。

所有页面使用简体中文，支持桌面和移动端。

## 三、核心页面

### 1. 首页 / 拼车广场

展示正在招募的拼车。

支持：
- 搜索拼车
- 按商品和成员位置筛选
- 查看剩余位置
- 点击查看拼车详情

### 2. 发起拼车

车主填写：
- 拼车标题
- 活动名称
- 商品名称
- 商品价格
- 开放的位置及数量
- 截单时间
- 拼车说明

提交后创建拼车，并展示在广场。

### 3. 拼车详情

展示：
- 车主昵称
- 活动与商品信息
- 价格
- 可选位置
- 已占位置
- 截单时间
- 拼车规则

车员选择空余位置后，点击加入拼车。

进入模拟支付确认页面，确认后完成上车。

已占位置不可重复选择。

### 4. 我的拼车

分为：
- 我加入的拼车
- 我发起的拼车

可以查看车次状态并进入详情。

### 5. 车主管理

车主可以：
- 查看车员名单
- 查看已占位置
- 查看拼车进度
- 点击“确认拼成”

确认后更新车次状态，并自动创建该车次的站内群聊。

### 6. 拼车群聊

每辆拼成的车自动对应一个群聊。

实现：
- 展示群成员
- 自动生成群昵称，允许修改
- 自动生成群公告模板，车主可以修改
- 群成员发送和查看文字消息

群聊使用本地模拟数据，不需要实时通信服务。

## 四、模拟数据

预置 NCT DREAM 周边拼车示例。

包含多个车主、不同商品、不同成员位置以及不同拼车状态。

示例数据只用于演示，不代表真实活动信息。

## 五、交互要求

所有主要按钮必须真实可用。

确保以下流程可以完成：

车主发布拼车 → 车员在广场找到车次 → 选择空余位置 → 模拟支付 → 加入拼车 → 车主确认拼成 → 自动建群 → 车员进入群聊。

需要提供基本的表单校验、操作反馈、空状态和错误提示。

页面刷新后，本地数据应保留。

## 六、UI 设计

设计风格：简洁、现代、轻量化，适合年轻粉丝使用。

采用浅色背景和柔和的紫色作为主要强调色。

重点做好：
- 顶部导航栏
- 拼车信息卡片
- 商品位置选择界面
- 拼车进度展示
- 发布拼车表单
- 群聊界面

布局清晰，交互直观，避免不必要的复杂功能。

## 七、开发要求

请直接生成完整可运行的网页项目，而不是只提供设计建议。

优先完成所有页面之间的导航与核心业务闭环。

确保模拟支付、位置占用、拼成确认和自动建群之间的数据状态正确关联。

完成后提供网页预览和运行说明。

不要自行扩展上述范围之外的功能。
